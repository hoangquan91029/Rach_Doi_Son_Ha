# Source-bound Blender candidate adapter499

`python3 scripts/blender/export_job.py /absolute/job.json` validates and prints a plan without importing bpy or rendering. Input and output paths are relative to the job folder, contained after symlink resolution; output must not exist. No overwrite, script evaluation, image generation, compiler invocation or deployment is performed.

Future actual Blender execution, only after selected model/rig/camera and source qualification, is `blender --background --disable-autoexec /absolute/qualified.blend --python /absolute/scripts/blender/export_job.py -- /absolute/job.json --render`. This command is documentation, not an executed or qualified route. Actual Blender execution/version are UNKNOWN here. The adapter rejects unsaved data, enabled auto-execution, mismatched opened asset, missing mesh/armature/action/camera, mirrored scale, camera basis mismatch, animated camera/scale fitting. It renders whole fixed canvas RGBA PNGs with no trim or pixel transformation. Failed partial outputs are preserved; choose a newly authorized output folder, do not overwrite them.

Schema `rds-blender-job/v1` requires exactly: `schema,id,identity,action,direction,original,view,blend,selection,qualification,layout,frames,loop,output,candidate`. All four pins are `{path,sha256}`; original/view are immutable identity authority, blend is source asset, qualification is the independently reviewed selected model/rig/camera JSON. The selection is exact `{scene,model,rig,camera,action}` object names. `candidate` must be true. Known canonical identity/action/counts come from actual `shared/unit-action-spec.js`, directions are integers0–7; no aliases or invented slots.

Layout is `{fixedCanvas:{width,height},cell:{width:128,height:128},pivot:{space:"source",x,y},render:{width,height},contactShadow:{mode:"baked"},camera:{projection:"dimetric",ratio:[2,1],tile:[54,27],elevation:26.565}}`; separate shadow uses `{mode:"separate",assetId}`. Square fixed source/layout matches current unit compiler envelope. Frames are exact `{slot,blenderFrame,phase,durationMs,status:"candidate"}`, slots0..count−1, phase=slot/count, distinct Blender frame indices, explicit loop/death cap. Per-frame transforms/layout fields are forbidden.

Qualification schema `rds-blender-selection/v1` requires `status:"qualified"`, `bindings` equal job identity/action/direction/original/view/blend/selection/layout/frames/loop, and `identityReview,modelReview,rigReview,cameraReview:"VERIFIED"`. These fields check declared bytes and relationships, not authenticity or art quality. Root must supply actual independent reviewed evidence before using render. No qualification is fabricated in this package. The tests use synthetic records solely to exercise failure gates.

Projection: renderer maps world XY to `(27(x−y),13.5(x+y))`. For equal orthographic world scale, physical elevation is30°, since sin(elevation)=.5. The engine label26.565° is the ground screen-axis slope, not the physical camera elevation. Engine `(x,y,z)` maps to Blender `(x,−y,z)`; camera world local X=(√.5,√.5,0), local Y=(−√.125,√.125,√.75), local Z=(√.375,−√.375,.5). Plan records engine right/up vectors and world pixel scale27√2. Direction D uses world vector `(cos(Dπ/4),sin(Dπ/4))`; no mirroring/automatic object rotation is applied. Selected authored action must already match the direction and original view. Original illustration projection mismatch remains a qualification blocker.

Output receipt contains mapping/raw SHA256, source asset pins, Blender version (only actual render), and separate UNKNOWN visual/motion/runtime/owner/release gates. PNG decode/alpha/RGBA hashes and independent appearance/motion review remain downstream dependencies. It does **not** emit a compiler job or claim compiler support for Blender provenance. Legacy schema2/3 and runtime schema1 are untouched. Exported PNGs require real custody, decoded verification and a separately qualified adapter into the existing compiler before integration; animation markers never own simulation damage/cargo/cooldown/outcomes.
