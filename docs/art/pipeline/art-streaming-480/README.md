# Opt-in decoded artwork paging 480

Source implementation only; no deployment, browser or art-coverage qualification.

`loadPolicy: "on-demand"` explicitly defers an asset; absent policy preserves legacy eager startup. Idle, terrain, UI, portraits and recursive separate-shadow dependencies remain eager. Manifest validation and fixed family/alias layout checks still cover the selected descriptors. Encoded prime skips deferred files, and match activation checks the eager set while retaining selected `availableIds` for subsequent requests. Declaring deferred assets does not create artwork or grant approval.

`pipeline.get` for an available exact deferred asset queues its own fetch/hash/decode and returns an image-null placeholder with `pending: true` until ready. This permits the existing renderer fallback without gameplay commands. Deferred loads serialize their budget reservations. LRU eviction closes only deferred unique image pages, removes all loaded aliases to that page, and keeps encoded bytes for re-decode. Eager pages and shared eager aliases cannot be evicted. A page returned by `get` is pinned through the current JavaScript task, protecting synchronous canvas rendering; callers must reacquire images through `get` rather than retaining them across frames. All pin timers are canceled on dispose.

The default decoded limit remains 128 MiB and encoded bank limit remains 64 MiB. Neither limit is increased. A working set containing eager and currently pinned pages that cannot fit causes an explicit `pageErrors` record and an image-null result. Errors are not automatically retried every frame; `pipeline.retry(id)` permits an explicit later retry. `stats.pending`, `pageErrors`, `evictedPages`, retained/reserved bytes and unique image count expose paging state; `whenIdle()` allows deterministic observation. Encoded storage has no eviction: reaching 64 MiB fails visibly. Offline re-decode works only for pages fetched and retained previously; unseen deferred pages still require connectivity. Startup never promises full-roster decode readiness for opted-in assets.

Dispose aborts pipeline-owned controllers, releases decoded images and reservations, clears pending selections/timers, and closes late decoded images without restoring disposed pages. Existing art-bank epoch checks prevent late match activation. Eager legacy startup behavior is covered unchanged.
