# Building compiler schema3

Use existing `python3 scripts/sprite-production.py /absolute/job.json --mode diagnostic|selected|production`. Legacy schemas1/2 retain unit behavior. New schemaVersion3 requires kindbuilding, known buildingType, family equaltype or building.type, actionconstruction/hit/death/attack, directionnull. Actual damage from shared/data.js limits attack applicability. No locomotion or nonempty previewBank permitted.

Keep existing compiler job fields id, family, action, master/masterSHA, fixedCanvas, cell, pivot, render, contactShadow, callBudget, frameCount, frames, loop, layout.columns, output. Add canonicalDescriptor `{path,sha256}` pinning actual original asset JSON, originalMaster `{path,sha256,rgbaSha256}` exactlyequal master. Canonical source SHA/canvas/cell/pivot/render/shadow bind these fields. No forced humanoid128 conversion. Residence actual source1254square, cell512square, pivot640/970source, render130square, bakedshadow remain fixed. Construction must loop; all other states require explicit booleanloop; death must be false and≤4000ms. No source trimming/mirroring/per-frame fitting.

Frames use existing `{phase,durationMs,status,input:{path,sha256,rgbaSha256},custody,events?}`. Selected mode requires selectedstatus/custody. Raw fullcanvas independently becomes working256 and runtime canonicalcell; fixed padding2 creates stridecell+4. Four512frames at2columns export1032square atlas; >2048 rejects instead of fitting. Existing hash/RGBA/status/custody/event/memory/overwrite guards remain.

Production retains existing qualification pin/status/masterSHA/family/action/direction/frameSHAs checks and attack event requirement. Building qualification additionally binds kindbuilding, buildingType, directionnull, canonicalDescriptorSHA, fixedCanvas, cell, pivot, render, contactShadow. No unit-style record can authorize it. Exported descriptor remains CANDIDATE with loadPolicyon-demand; successful packaging is not approval.

Diagnostic one-key packages may support source examination but are not completed state clips. True full construction/hit/death/attack banks require authored phase distinctions, independent quality/actualruntime and owner acceptance. PreviewBank is explicitly unavailable for building jobs rather than inventing octants. Temporary fixture exports are deleted by tests; tests reuse original source to prove geometry only.
