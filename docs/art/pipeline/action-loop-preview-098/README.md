# Generic actual action preview098

Thin extension of frozen017, which already supplies atlas, contact sheet, custody validation and declared-frame preview. This helper adds metadata-based real-size APNG and an actual client-loader preview. It accepts the same exact017 job and rejects technical fixtures. No source frame is synthesized or fitted; all source/selection hashes, distinct RGBA phases, fixed canvas/pivot, declared timing/events, shadow dependency and1..256-frame validation remain017.

Invoke after every declared slot is actually selected and hash-bound:

```
python3 docs/art/pipeline/action-loop-preview-098/build.py /absolute/selected-actual-job.json /absolute/new-output
```

Serve the repository locally; open the output `loader-preview.html`. This imports the actual client raster pipeline. Dynamic state/direction/frame count, atlas rectangles, durations, render size and pivots come from exported manifest metadata. Loop jobs repeat; nonloop jobs use APNG loop1 and the real loader's terminal hold. Single-frame jobs produce static PNG. No action aliases or gameplay events are invented; names such as gather_food/gather_wood/build/hit/death are job declarations, not evidence that runtime routes artwork. Frozen017 forbids looping death. The existing runtime matrix remains authoritative.

The generated contact sheet is the original017 output. APNG and loader preview share metadata-based bounds and anchor with padding, including separate authored shadow. They show declared render size; browser interpolation/APNG resampling may differ slightly. Nothing grants motion, identity, foot lock, gameplay, owner or public approval.

Compatibility uses complete selected actual024 wood/D1 sources only, not a new art order or motion-review repeat.096 is not exported and no missing slot is filled. Parent reviews this helper before any096 export.
