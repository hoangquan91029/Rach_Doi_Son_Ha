# Four-key internal bitmap baker — tooling v3 (input schema remains v2)

This tool produces four complete 1254×1254 transparent RGBA PNG keys only: F0/F2/F4/F6, fixed pivot(654,1140), whole-canvas logical38px. It is an internal authoring tool, never a runtime puppet. Actual sources remain absent. No image calls, final-art approval, motion qualification, atlas, intermediate frames or runtime integration follow from these checks.

Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_bake_keys.py`. Pillow is required. Tests create and destroy only temporary explicitly NON_ART bitmap components. They recover raster landmark color centroids and compare world planting after root travel (1.5source-pixel tolerance), and inspect seam alpha, source/output hashes, custody/refusal, fixed lengths and world planting. They do not establish painted anatomy, identity continuity or motion quality.

Commands:

- `python3 bake_keys.py inspect-sidecar PART_ID absolute-sidecar.json`: read-only single original calibration/mesh technical check, reporting PARTIAL_REST_INSPECTION_ONLY with source hashes/calibration and no full-character/animation-key claim; permits the finite core pilot to prepare without eight other originals. No image call authorization or baking.
- `python3 bake_keys.py bake absolute-manifest.json nonexistent-output-directory`: complete nine-part preflight first, then stage four whole PNGs and receipt with Linux atomic renameat2 NOREPLACE publication. Other platforms refuse unsupported publication rather than risk overwrite. Existing output is refused. Missing or unknown components produce no output. Normal failures return JSON refusal/exit2. Output parent must already exist.

## Calibration and camera correspondence

The JSON schema is `south-bitmap-rig-sidecar/v2`. Each sidecar binds one original part, source byte+decodedRGBA hashes, inspected natural landmarks, and ONE immutable uniform raw-to-rest scale/rotation/translation. All values must be finite. Exact rest calibration tolerance is0–2source px; measurement uncertainty is disclosed separately and never licenses per-frame fitting. Canonical source images and held whole-character frames are never extracted, traced, edited or substituted as parts.

For a limb, canonical rest localXY is a straight bone plane with proximal(0,0) and distal(0,L), L200/180arms or260/240legs. One calibration must map actual inspected endpoints onto that plane. For the core, restXY is fixed full-canvas source screen space. One calibration must map LEFT/RIGHT shoulder caps to(834,300)/(474,300) and hidden hip hypotheses to(754,610)/(554,610). These are the current model attachment hypotheses, not exact measured anatomy; if real core cannot match without distortion, parent must revise the model contract once. Its genuine skeletal translation is the v2 pelvis lateral shift and leg-driven vertical bob. Source height/bounding box is never fitted per frame.

Each indexed mesh vertex has `rawXY` and `binding:{frame,local}`. For bone binding, local[x,y] is width and distance along a constant3D segment; width is globalX projected perpendicular to the segment. Fixed camera projection screen=(654+x,1140+0.5depth-z) may foreshorten the pose plane. This explicit geometric affine transform is separate from source calibration, and never changes the source-rest scale.

For foot binding, local[x,depth,z] is an immutable rigid offset from the ankle. South foot orientation is fixed in these four authored keys; the whole foot is translated by the independent ankle track, not rotated by the shin. Rest foot screenXY=(x,L+0.5depth-z). Actual heel(-50depth,-60z), toe(+110depth,-60z) and sole midpoint(+30depth,-60z) must correspond to inspected natural landmarks under that same static calibration. If a real source cannot meet this contract without distortion, REFUSE it; separate original foot textures may be necessary. This four-key tool does not claim heel-push/all-eight articulation.

Each integrated lower-leg texture uses indexed semantic `shin` and `foot` triangles. Their region boundaries must intersect exactly at the ordered sharedAnkleSeam. Seam vertices bind to the same rigid ankle/foot frame with depth0/z0. Shin transition triangles connect fixed-bone vertices to those shared seam vertices. Foot triangles exclusively use rigid foot vertices; no sole bending or shin-driven foot rotation is possible. This is explicit internal mesh articulation, not raw pixel repaint or alpha cleanup. Actual seam appearance still requires complete-character illustration review.

The renderer resamples immutable originals through these declared triangles using alpha-aware presentation sampling; it never writes source pixels. No bbox fit, mirroring, source alpha cleanup or source warp-normalization is performed. Per-pose layer order is explicit and review-bound; anatomical LEFT is viewerRIGHT, not permanently near. Cloth/limb overlap must be judged from actual art.

## Sealed input interface

Sidecar fields: schema, partId, status=`SEALED_ORIGINAL_CALIBRATION`, raw `{path:absolute,sha256,rgbaSha256,width:1254,height:1254}`, calibration `{scale,rotationRad,translation:[x,y],tolerancePx}`, landmarks, mesh.

Landmarks are objects `{xy:[sourceX,sourceY],method:observed_original|authored_hidden_hypothesis,uncertaintyPx,evidence}`. Hidden hypotheses are allowed only for hips and must be described honestly. Required core names: actor_left_shoulder_cap, actor_right_shoulder_cap, actor_left_hip_under_hem, actor_right_hip_under_hem. Required limb names follow bone endpoints: shoulder/elbow, elbow/wrist, hip/knee, knee/ankle. Lower-sandals additionally need independently observed heel, toe and solePlane. Unknown values remain missing and cause refusal; fixture coordinates are never a model for actual measurements.

Mesh: vertices `[{rawXY,binding}]`, triangles `[{indices:[i,j,k],region:core|bone|shin|foot}]`, sharedAnkleSeam `[ordered shared indices]` (empty for all other parts). Mesh source/rest correspondences are checked against calibration. No independent per-frame calibration is accepted. Mesh regions must have consistent source winding, nonoverlapping interiors, exact shared ankle boundaries, and cover every original nonzero-alpha pixel (including fringes); omitted alpha is refused rather than cleaned or cut. Projected folds/mirrors and off-canvas geometry are refused before staging. Actual author must seal sufficient joint overlap; numeric checks do not judge painted seam quality.

Manifest schema=`south-four-key-bake/v2`, purpose=`ACTUAL_ORIGINAL_PARTS` or strictly `NON_ART_TEMPORARY_FIXTURE`, parts maps exactly the nine contract IDs to `{path:absolute-sidecar,sha256}`, layerOrderByKey contains exactly F0/F2/F4/F6, each all nine IDs once. reviewReceipt `{path,sha256}` binds separate reviewed status=`SEALED_PART_CALIBRATIONS_FOR_FOUR_KEY_AUTHORING`, contractSha256, posePlanSha256, all sidecarHashes, and layerOrderByKey. The NON_ART route requires status NON_ART_TECHNICAL_FIXTURE_ONLY and always produces NON_ART_AUTHORING_DIAGNOSTIC_NOT_QUALIFICATION; it cannot acquire actual-art status through test success.

Actual output status is SOURCE_BAKED_RIG_REQUIRES_FINISHED_ILLUSTRATION_REVIEW, candidate=false. Receipt binds source/output byte and decodedRGBA hashes, key times/support/swing, pivot, actual transformed mesh vertices and the explicitly provisional stride/cadence hypothesis. Four-key review must assess identity, painted anatomy, contact, overlap, seam and38px readability before any in-between/atlas work. No finished animation exists merely because this baker runs.

## v3 custody correction

Prior tooling-v2 remains sealed and unchanged. Before either single-sidecar inspection or baking, v3 verifies the actual eight N/NE/E/SE/S/SW/W/NW originals: byte SHA, decodedRGBA SHA, RGBA1254 dimensions, direction mapping, full-body-inspected flags and candidate status. It verifies the hash-bound parent review receipt, all eight reviewed byte/RGBA records, camera/canvas/pivot/38px, and South-only authoring scope. The same checks run again before atomic publication. A lock JSON hash alone no longer substitutes for its live original sources. Identity gate fixtures are temporary NON_ART numeric rasters and cannot pass the actual hard-bound contract path/lock gate.

All source hip pivots (core and thighs) must say authored_hidden_hypothesis. Guides do not measure hidden anatomy. Duplicate rawXY vertices are refused; shared seam regions must reuse one indexed vertex, not coincident copies. All existing source calibration and output schemas remain unchanged. Actual-source pixel/attachment fit and finished-illustration quality remain parent-review gates.
