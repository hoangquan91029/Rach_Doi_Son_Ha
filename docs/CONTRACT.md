# Integration contract (2026-10-07)
ES modules JS; browser Canvas2D; Vite client; Node HTTP + ws authoritative server; shared pure simulation. Root owns package/config/assets/deployment/audit. No edits to original leadership directory.

## shared API (simulation owner)
`shared/data.js`: exports UNITS, BUILDINGS, CHARACTERS (object keyed by folder ids; label/name,tags,description,ability), MAPS (array id,name,description), TICK_RATE=20.
`shared/sim.js`: exports createMatch({mapId='delta',seed=1,players:[{name,king,general},{name,king,general}],aiPlayer=null,difficulty='normal'}), step(state), command(state,player,cmd) => {ok:boolean,error?:string}, view(state,player), hashState(state).
state/view: {tick,map:{id,width,height,tiles:[terrain string flat row-major],resources:[{id,type,x,y,amount}]},players:[{id,name,king,general,resources:{wood,food,iron},population}],entities:[{id,owner,type,kind:'unit'|'building',x,y,hp,maxHp,food,foodMax,morale,state,dir,queue?,cargo?,character?}],winner:null|0|1,reason,events:[]}. positions in tile coordinates. Commands: {type:'move'|'attackMove'|'stop'|'hold',ids:[entity IDs],x,y}; {type:'attack',ids,target}; {type:'gather',ids,target:resource ID}; {type:'build',ids:[builder ID],building:BUILDINGS key,x,y}; {type:'train',building:entity ID,unit:UNITS key}; {type:'load'|'unload',ids:[wagon/transport ID],target:entity ID}; {type:'ability',ids:[leader ID]}; {type:'surrender'}.
Unit keys: villager,king,general,infantry,spearman,firearm,cavalry,artillery,wagon,warship,transport.
Building keys: residence,barracks,cavalryCamp,artilleryWorkshop,shipyard,fort,wall,gate,depot,granary.
Tiles: plain,forest,hill,mountain,river,sea,ford. view includes fog:{visible:boolean[],explored:boolean[]} and hides unseen enemy entities. Return sufficient friendly entities & data for HUD. General death wins immediately; residence death does not. 1 residence includes construction reservation; client resources never authoritative. Events user-facing strings allowed.

## Server protocol (server owner)
Node exported createGameServer({port=3000,host='127.0.0.1',...}) returns {server,wss,rooms,close}; run `server/index.js`. Serves Vite production dist and GET /health. WS /ws same origin.
Client requests {type:'create',name,king,general,mapId}, {type:'join',code,name,king,general}, {type:'resume',code,token}, {type:'configure',king,general,mapId?}, {type:'ready',ready:boolean}, {type:'command',command:simCmd}, {type:'rematch'}, {type:'leave'}, {type:'ping'}.
Responses {type:'joined',code,player:0|1,token,lobby}; {type:'lobby',code,players:[{name,king,general,ready,connected}],mapId,status}; {type:'start',player,state:view}; {type:'state',state:view,paused:boolean,reconnectRemaining?}; {type:'error',message}; {type:'pong'}. State snapshots 5Hz, sim 20Hz. No clients simulate online. 60s disconnect pause, resume token independent of nickname. Exactly two seats; ready required; postmatch rematch only after both consent. Lobby changes clear readiness. Message size/rate limit; auth ownership; reject malformed JSON/unknown commands.

## Client (UI owner)
Root index.html, client/main.js, client/style.css, client/renderer.js owned by UI agent. Import shared modules. Vanilla DOM no framework needed. Menu single/online, selection for 12 leaders, map selection, nicknames, create/join/link, lobby ready, matching end & rematch. Offline sim uses fixed accumulator; online state authoritative snapshots. Canvas isometric map renderer & minimap; click/drag/shift/commands/control groups, WASD/arrow pan, wheel zoom; HUD resources/leaders/selection/rations/cargo/queue/build/train/abilities. Assets /assets/leadership/<id>/D00.webp ... D07.webp (not all dirs may exist, fallback renderer); data JSON /assets/leadership/manifest.json. Root handles images. Original programmatic terrain/building/unit art acceptable prototype but explicitly record final visual gaps.
