# Pixel animation specification535

Runtime metadata schema: rds-pixel-clip/v1. Required fields: schema, identity, action, atlas (same-origin root-relative PNG URL), cellSize128, atlasSize1024, frameCount8, directions [S,SW,W,NW,N,NE,E,SE], anchor [64,112], renderSize [64,64], frameDurationsMs (eight positive integer durations), loop (boolean), events (array of {name,frame}), palette (array of distinct #rrggbb colors), review {structural,visual,runtime}, provenance. Reject unknown fields rather than infer them. Provenance records actual source paths/hashes and call tokens; metadata cannot authenticate visual quality. null/unknown review is not approval. New assets remain outside the active approved registry until automated, visual and engine gates pass.

One1024×1024 atlas per identity/action; row r is direction r; cell rectangle [128*f,128*r,128,128]. Exactly8frames per direction; future >8 requires a new layout schema, never silent truncation. Canonical actions mirror shared/unit-action-spec.js; pixel chop_tree aliases only to villager gather_wood. All living action counts minimum8, including idle/hit/ability. No death art; HP0 hides and existing simulation continues to own damage, cargo, outcomes.

Engine D0→SE row7, D1→S row0, D2→SW row1, D3→W row2, D4→NW row3, D5→N row4, D6→NE row5, D7→E row6. World projection compresses diagonal slopes; row names are projected visual octants, not world axes. Do not change simulation facing.

Idle proposed1600ms; walk800ms; chop800ms. Eight durations, no repeated endpoint at F7. Walk runtime advances with measured traveled distance and a reviewed stride, never wall time while stopped. Until stride measured, walk runtime qualification remains OPEN. Other loops use bounded simulation time; finite clips clamp to final frame, emit markers once per action instance, reset on reentry, freeze on Pause. Markers never apply damage or cargo. Attack/hit/ability/load/unload use authoritative event/tick origin. Stop enters idleF0. Missing clips must remain explicit missing, never borrow character images or fabricate frames.

Registry schema rds-pixel-registry/v1 has exact fields schema, clips, strides. Both arrays initially empty. Each stride record has exact fields identity, distancePerCycle (positive world distance), evidence {path,sha256}, review (PASS); one per identity. It binds measured same-foot stance evidence; metadata cannot prove foot lock. Missing stride leaves walk explicitly unqualified. Runtime bank uses per-identity stride lookup. A separately explicit candidate-only constructor option may load structural-PASS clips with visual/runtime UNKNOWN in a private test stage for qualification; default active registry still requires all three PASS. Candidate loading never promotes or changes the active registry. Complete Worker pilot: idle/walk/chop_tree ×64 =192 actual distinct poses (chop same-action mapping stated above). Every later unit uses applicability from shared/unit-action-spec.js; no mass production before independently reviewed Worker loop and in-engine transition.
