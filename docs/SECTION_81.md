# Final completion criteria — user update, 2026-10-07

The project is COMPLETE only when a normal user can receive a public HTTPS link, open it in a desktop browser, and play without installing anything. Both complete modes are required: local Single Player human vs AI and Online human vs human exactly 1v1.

## Acceptance ledger
Every entry requires implementation and evidence. A prototype, production build, static imagery, test pass, deployment URL, or localhost demonstration alone does not close other gates.

- [ ] Public HTTPS; clean-browser loading; production build; Chrome/Chromium; Firefox where practical; no player installation.
- [ ] Menu; Single Player; Online 1v1; map/King/General selection; loading; victory/defeat; return to menu.
- [ ] Local AI economy/army/logistics, General protection, normal win/loss.
- [ ] Two-seat rooms; create/join/code/link; ready; synchronized match; disconnect; reconnect; synchronized victory; rematch.
- [ ] Villagers, wood/food/iron gathering, buildings and production, infantry/spearmen/firearms/cavalry/artillery/ships/combat, fog, terrain effects.
- [ ] Historical King/General choices; distinctive passive/active modifiers; synergy; General death defeat.
- [ ] One Main Residence including construction reservation; villagers; healing; destruction without defeat; King replacement only after destruction; no duplication.
- [ ] Continuous ration consumption; finite Granary inventory; Supply Depot; Supply Wagon; frontline food transport; raidable chain; remote wood/iron transfer.
- [ ] Two finished maps playable in both modes; rivers/sea/plains/forests/hills/mountains/ambush/naval/multiple attacks/supply routes.
- [ ] Original readable 2.5D presentation; major unit eight-direction idle/walk/attack/hit/death; UI; minimap.
- [ ] Fixed tick; measured browser performance; no known severe desync; validated commands; no major resource exploits; reconnect; no major game-breaking bugs.
- [ ] Clean browser loads public link; two separate browsers/devices join room; full 1v1 finishes through public production server.

Until all critical requirements pass: **NOT COMPLETE**.
